## Figure 1 and supported rendering

The overview is supplied as [PNG](figures/Figure_1.png) and [vector PDF](figures/Figure_1.pdf) assets. For Figure 1, the rendering entrypoint exports those files directly (`asset_export`) without reconstructing the illustration from raw molecular data; an earlier schematic remains archived at [`figures/source/Figure_1.svg`](figures/source/Figure_1.svg) as a historical file.

For the numerical figures, the portable entrypoint uses frozen display values and the retained plotting functions. It renders the values shown in Figures 3–6 and S1–S3 without fitting models, changing saved predictions or recalculating the scientific analyses. The output follows an earlier plotting layout: the panel arrangement, dimensions and annotations of the paper's figures are not generated by this entrypoint.

```bash
python -m pip install -r environments/figures.txt
python scripts/render_paper_figures.py
```

Use a separate plotting environment as described in [the source guide](figures/source/README.md). Generated figures go to a fresh ignored `runs/` directory; the repository does not carry a full set of publication exports. Each run writes a rendering receipt (`RENDERING_RECEIPT.json`) with its environment and outputs to the output directory. Font substitution can change text geometry relative to a run with Arial.

Figure 2 combines a chemical example and numerical annotations; [FIGURE_2_SOURCES.md](docs/FIGURE_2_SOURCES.md) maps its displayed values to the frozen identity, split and diagnostic records. Its complete historical production chain has not been made portable here.

## Read the scopes separately

Start with [REPRODUCING.md](REPRODUCING.md) for the default command and its coverage matrix. [docs/SCIENCE_COVERAGE.md](docs/SCIENCE_COVERAGE.md) identifies the supplied scientific layers and historical boundaries.

This mapping does not turn saved-result agreement into prospective validation or recover missing historical execution dependencies. Population definitions, undefined scores and the selected model/null comparison must be interpreted in their original scope.
